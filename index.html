Функциялар
және жолдар

Программаны ішкі программаларға бөлу және мәтіндерді өңдеу.

01 · ПРОЦЕДУРА

Процедура

Мақсат: процедураларды пайдаланып Python тілінде код жазу.

Ішкі программа — белгілі бір алгоритм бойынша әрекеттерді орындайтын және атауы арқылы шақырылатын программаның бөлігі. Ішкі программалар қайталанатын кодты бір рет жазып, бірнеше рет қолдануға мүмкіндік береді.

Процедура — белгілі бір әрекетті орындау үшін шақырылатын ішкі программа. Мысалы, хабарды экранға шығару немесе есептелген шаманы көрсету. Ол def қызметтік сөзі арқылы анықталады.

Python-да процедураға арналған бөлек қызметтік сөз жоқ: ол да def арқылы анықталатын функция нысаны. Осы сабақта мәнді return арқылы арнайы қайтармай, әрекет орындайтын ішкі программаны «процедура» деп атаймыз. Оның жасырын қайтарылатын мәні — None. print() экранға шығарады, ал return шақырған кодқа мән қайтарады.

Параметрсіз

Анықтамадағы жақша бос: def salem():. Шақыру: salem().

Параметрлі

Жұмысқа қажетті мәндер параметрлер арқылы қабылданады: def perimetr(a, b):. Шақыру: perimetr(2, 3).

Атаудан кейін дөңгелек жақша және қос нүкте қойылады. Денесі төрт бос орынмен шегіндіріледі. def орындалғанда процедураның атауы анықталады; денесі сол сәтте орындалмайды. Денені орындау үшін процедураны шақыру керек.

Параметрсіз процедура · salem()

Процедура екі жол шығарады. Екі рет шақырылса, денесі екі рет орындалып, барлығы төрт жол шығады. Шақыруларды алып тастап, def анықтамасының өзі экранға мәтін шығармайтынын тексер.

def salem():
    print("Salem, aryptester ")
    print("Sizdermen: Azamat Rashiduly")

salem()
salem()
Кодтың әр жолының түсіндірмесі
  1. def арқылы salem атаулы параметрсіз ішкі программа анықталады. Тақырыпша соңында қос нүкте бар.
  2. Төрт бос орынмен шегіндірілген бірінші print процедура денесіне жатады. Ол шақыру кезінде орындалады.
  3. Екінші print сол шақыру кезінде келесі жолға мәтін шығарады.
  4. Бос жол оқуға ыңғайлы болу үшін берілген.
  5. salem() — бірінші шақыру. Орындау процедура денесіне өтеді.
  6. salem() — екінші тәуелсіз шақыру; екі print қайта орындалады.

Параметрлі процедура · perimetr(2, 3)
Екі процедура анықталған, бірақ негізгі программада тек perimetr шақырылған. Сондықтан аудан есептейтін audan денесі орындалмайды. Периметр P = 2 × (a + b) формуласымен есептеледі.
def audan(a, b):
    s = a * b
    print("Audany:", s)

def perimetr(a, b):
    p = 2 * (a + b)
    print("Perimetri:", p)

perimetr(2, 3)
Кодтың әр жолының түсіндірмесі
  1. audan процедурасының a және b параметрлері анықталады.
  2. s — ауданның жергілікті айнымалысы.
  3. Ауданды экранға шығарады. Бірақ audan шақырылмаса, бұл жол орындалмайды.
  4. Бос жол код бөліктерін ажыратады.
  5. perimetr процедурасының a, b параметрлері.
  6. p — осы шақырудағы жергілікті периметр.
  7. Есептелген периметр экранға шығады.
  8. Бос жол негізгі программаны бөледі.
  9. 2 және 3 — аргументтер. a = 2, b = 3 болып байланысады; тек perimetr денесі орындалады.

ЖазылуыМағынасы
def audan(k, p):k және p — формалды параметрлер
audan(a, b)a мен b мәндері — аргументтер; атаулардың бірдей болуы міндетті емес

Осы сабақтағы екі міндетті параметрі бар процедураға екі аргумент беріледі. Аргумент жетіспесе немесе артық берілсе, TypeError пайда болады. Әдепкі мәндер мен айнымалы аргументтер саны кейінгі тақырыптарда қарастырылады.
Жергілікті және ауқымды айнымалылар
Жергілікті айнымалы процедура шақырылған кезде оның ішінде жасалады. Параметрлер де жергілікті атауларға жатады. Бұл атаулар процедурадан тыс негізгі программаға тікелей көрінбейді.
Ауқымды айнымалы негізгі программада, яғни модуль деңгейінде анықталады. Процедура ішіндегі және сыртындағы атаулар бірдей болса да, олар әртүрлі ауқымдағы тәуелсіз атаулар бола алады.
Сыртқы айнымалыны процедура ішінде тек оқу үшін global міндетті емес. Ал сол сыртқы атауға жаңа мән меншіктеу керек болса, процедура ішінде global жазылады. global айнымалыны барлық файлға автоматты түрде ортақ етпейді; ол осы модульдің ауқымына қатысты.
Бірдей атау, екі бөлек айнымалы · p
Сыртқы p = 55 өзгермейді. Процедура ішіндегі жергілікті p = 10 тек сол шақыруға жатады. Анимацияда екі p бөлек жад аймақтарында көрсетіледі.
def perimetr(a, b):
    p = 2 * (a + b)
    print("Perimetri:", p)

p = 55
perimetr(2, 3)
print(p)
Кодтың әр жолының түсіндірмесі
  1. Параметрлі процедура анықталады.
  2. Меншіктеу процедураның жергілікті p атауын жасайды.
  3. Процедура ішіндегі p мәні шығады.
  4. Бос жол.
  5. Негізгі программадағы p = 55 — бөлек, ауқымды айнымалы.
  6. Шақыру кезінде жергілікті a = 2, b = 3, p = 10 пайда болады.
  7. Шақыру аяқталғаннан кейін негізгі программадағы p мәні, яғни 55 шығады.

global p · сыртқы мәнді өзгерту
global p жазылғаннан кейін процедурадағы p сыртқы p атауымен байланысады. Периметр есептелгенде негізгі программадағы 55 мәні 10-ға өзгереді.
def perimetr(a, b):
    global p
    p = 2 * (a + b)
    print("Perimetri:", p)

perimetr(2, 3)

  4. Өзгерген ауқымды p мәні экранға шығады.

1-мысал · Санның таңбасын анықтау
N бүтін саны берілген. Теріс сан болса, параметрсіз ANIKTAU процедурасы шақырылады. Оң сан және нөл негізгі программадағы бөлек тармақтарда қарастырылады. Нөл оң да, теріс те сан емес.
def ANIKTAU():
    print("Teris san")

n = int(input("Sandy engiz="))
if n < 0:
    ANIKTAU()
elif n > 0:
    print("On san")
else:
    print("Nol")
Кодтың әр жолының түсіндірмесі
  1. Параметрсіз ANIKTAU процедурасы анықталады.
  2. Шақырылса, теріс сан туралы хабар береді.
  3. Бос жол.
  4. n бүтін саны пернетақтадан оқылады.
  5. n теріс пе — тексереді.
  6. Шарт ақиқат болса, процедура шақырылады.
  7. Бірінші шарт жалған болса, санның оң екені тексеріледі.
  8. Оң сан үшін хабар шығады.
  9. Екі шарт та жалған болса, сан нөлге тең.
  10. Нөл бөлек көрсетіледі.

2-мысал · Тіктөртбұрыштың ауданы мен периметрі
Ұзындық a және ені b берілген. Екі параметрлі процедураны кезекпен шақырып, аудан мен периметрді есептейміз. Анимацияда енгізілген мәндердің k, p параметрлеріне берілуі көрсетіледі.
def audan(k, p):
    print("audan=", k * p)

def perimetr(k, p):
    print("perimetr=", 2 * (k + p))

a = int(input("Uzyndygyn engiz="))
b = int(input("Enin engiz="))
audan(a, b)
perimetr(a, b)
Кодтың әр жолының түсіндірмесі
  1. k, p — аудан процедурасының параметрлері.
  2. Аудан S = k × p формуласы арқылы есептеліп шығады.
  3. Бос жол.
  4. Периметр процедурасы анықталады. Оның k, p параметрлері өз шақыруына жергілікті.
  5. P = 2 × (k + p) есептеледі.
  6. Бос жол.
  7. Ұзындық a бүтін саны ретінде енгізіледі.
  8. Ені b бүтін саны ретінде енгізіледі.
  9. a, b мәндері audan процедурасының k, p параметрлеріне беріледі.
  10. Сол a, b мәндері perimetr процедурасының k, p параметрлеріне беріледі.

Практикалық жұмыс
Тапсырманың алгоритмін өзің құрастыр. «Жауабын көру» ішінде толық код, түсіндірме және қадамдық орындалу көрсетілген.
Практика №1 · Екі санның үлкені
a, b сандары берілген. Осы екі санның үлкенін анықтап, экранға шығаратын параметрлі процедура құрастыр. Сандар тең болса, ортақ мәнін бір рет шығар.
Жауабын көру · код және анимация
def mm(a, b):
    if a > b:
        print(a)
    else:
        print(b)

mm(23, 15)
Кодтың әр жолының түсіндірмесі
  1. a және b параметрлері бар mm процедурасы.
  2. Екі мән салыстырылады.
  3. a үлкен болса, a шығады.
  4. Кері жағдайда орындалатын тармақ.
  5. b үлкен немесе тең болса, b шығады. Тең сандардың ортақ мәні бір рет шығады.
  6. Бос жол.
  7. 23, 15 аргументтері беріліп, процедура шақырылады.

Практика №2 · Аралықтағы жұп сандар
k, n бүтін сандары берілген (k ≤ n). [k; n] аралығындағы барлық жұп санды, шекараларын қоса, экранға шығаратын процедура құрастыр. Әр сан жеке жолға шықсын.
Жауабын көру · код және анимация
def zup(k, n):
    for i in range(k, n + 1):
        if i % 2 == 0:
            print(i)

zup(1, 10)
Кодтың әр жолының түсіндірмесі
  1. Аралықтың шекаралары k және n параметрлері арқылы беріледі.
  2. range(k, n + 1) k-дан n-ге дейін, n-ді қоса аралайды.
  3. Санның 2-ге бөлгендегі қалдығы тексеріледі.
  4. Қалдық нөл болса, жұп сан жеке жолға шығады.
  5. Бос жол.
  6. 1, 10 аргументтерімен процедура шақырылады.

02 · ФУНКЦИЯ
Функция
Мақсат: функцияларды пайдаланып Python тілінде код жазу және қайтарылған мәнді есептеулерде қолдану.
Функция — атауы бойынша шақырылатын, белгілі бір есепті орындайтын ішкі программа. return операторы есептеу нәтижесін функцияны шақырған кодқа қайтарады.
Процедура мен функцияның айырмашылығы
Процедура · әрекет орындау
Мысалы, хабарды экранға шығарады немесе файлға жазады. Осы курста нәтижені арнайы қайтармайтын ішкі программаны процедура деп атаймыз.
print → экран
Функция · мән қайтару
Есептелген мәнді return арқылы шақырған кодқа береді. Ол мәнді айнымалыға сақтауға, өрнекте қолдануға немесе экранға шығаруға болады.
return → шақырған код
Python тілінде екеуі де def арқылы анықталады. Бөлек «процедура» түрі жоқ: return-сыз аяқталған функция да None мәнін қайтарады. print() пен return бірін-бірі алмастырмайды; қажет болса, бір функцияның ішінде екеуін де қолдануға болады.
Функцияның жазылуы
def kosu(a, b):
    c = a + b
    return c
def — анықтау, kosu — атау, a, b — параметрлер. Дене төрт бос орынмен шегіндіріледі. c — осы шақырудың жергілікті айнымалысы. return c оның мәнін қайтарады және ағымдағы шақыруды бірден аяқтайды. Одан кейінгі жолдар сол шақыруда орындалмайды.
Анықтама функция денесін орындамайды. kosu(10, 2) шақырылғанда ғана 10 мен 2 аргументтері a және b параметрлеріне беріледі. Әр шақырудың жергілікті айнымалылары бөлек болады.
Аргументтер
10, 2→Функция
a + b→return
12→Негізгі код
12 − 5
Мәннің қайту жолы · kosu(10, 2) − 5
Алдымен функция орындалады. Қайтарылған мән шақырудың орнына қойылып, өрнек әрі қарай есептеледі.
def kosu(a, b):
    c = a + b
    return c

x = kosu(10, 2) - 5
print(x)
1. a = 10, b = 2 → c = 12.
2. return 12 мәнін береді; x = 12 − 5 = 7.
3. print(x) экранға 7 шығарады. Функцияның өзінде print жоқ.

Практика #3 · Аралықтағы сандардың қосындысы
k, n бүтін сандары берілген (k ≤ n). k-дан n-ге дейінгі барлық бүтін сандардың қосындысын қайтаратын функция құрастыр. Екі шекара да аралыққа кіреді.
Жауабын көру · код және анимация
def msum(k, n):
    s = 0
    for i in range(k, n + 1):
        s += i
    return s

k, n = map(int, input("Аралықты енгізіңіз: ").split())
x = msum(k, n)
print("Аралықтағы сандардың қосындысы:", x)
input().split() бос орынмен бөлінген екі мәнді оқиды, map(int, ...) оларды бүтін санға айналдырады. Енгізу үлгісі: 5 10.
s = 0 — бастапқы қосынды. range(k, n + 1) n мәнін қоса аралайды. Әр айналымда s += i қосындыны жаңартады. return s циклден тыс жазылғандықтан, тек цикл толық аяқталған соң орындалады.
x = msum(k, n) қайтарылған қосындыны сақтайды. Соңғы print хабармен бірге x мәнін шығарады.
Төбедегі өріске кез келген бүтін аралықты енгізуге болады. Қадамдық көрініс үшін 100 санға дейінгі аралықтың әр мүшесі көрсетіледі. Одан үлкен аралықтарда қосындының өзгерісі топтап көрсетіледі; код әр санды жеке қосады.

03 · РЕКУРСИЯ
Рекурсия
Мақсат: рекурсивті шақырудың орындалу ретін түсіну және рекурсияны қолданып есеп шығару.
Рекурсия — ішкі программаның өзін тікелей немесе басқа ішкі программалар арқылы шақыру тәсілі. Әр шақыру есептің кішірек бөлігін шешеді, кейін басқару алдыңғы шақыруға қайтады.
Рекурсияның үлкен сызбасы · 5!
Сол жақта шақырулар төмен қарай тереңдейді. Базалық жағдайдан кейін оң жақта мәндер жоғары қарай қайтады. Әр қадамда белсенді блок пен бағыт белгіленеді.
↓ Шақырулардың тереңдеуі↑ Нәтижелердің кері қайтуы
ДАЙЫН
5! = ?
Рекурсияның екі міндетті бөлігі
1. Базалық жағдай
Жаңа шақыру жасалмайтын тоқтау шарты. Мысалы, fact(1) бірден 1 қайтарады.
2. Рекурсивті қадам
Есепті базалық жағдайға жақындататын шақыру. Мысалы, fact(n − 1) аргументті бір бірлікке азайтады.
Әр шақырудың өз жергілікті n айнымалысы және жалғастыратын орны бар. Ішкі шақыру аяқталғанша сыртқы шақыру күтіп тұрады. Бұл сақталған шақырулар шақырулар стегі деп аталады: соңғы кірген шақыру бірінші аяқталады.
Тоқтау шарты орындалатындай аргумент беру керек. Шартқа жақындамайтын немесе тым терең рекурсия Python-да RecursionError қатесіне әкеледі. Төмендегі анимацияларға 1–8 аралығындағы бүтін n енгізіледі: барлық шақыруды бір сызбада көруге болады.
↓ Тереңдеу
Жаңа шақыру жасалады.
Алдыңғы шақыру күтіп тұрады.
■ Базалық жағдай
Жаңа шақыру жасалмайды.
Кері қайту басталады.
↑ Кері қайту
Күтіп тұрған код жалғасады.
Нәтижелер есептеледі.
Практика #1 · print қай кезде орындалады?
recur(4) шақыруының жұмысын талда. Экранға қандай сандар, қандай ретпен шығады? Рекурсивті шақыру print(n) жолынан бұрын тұрғанына назар аудар.
Жауабын көру · код және анимациялық сызба
def recur(n):
    if n > 1:
        recur(n - 1)
        print(n)

recur(4)
Кодтың орындалу реті
Тереңдеу: recur(4) → recur(3) → recur(2) → recur(1). Әр шақырудағы n — бөлек жергілікті айнымалы.
База: n = 1 кезінде n > 1 жалған. if денесіндегі шақыру да, print те орындалмайды. Бұл шақыру None мәнін қайтарып аяқталады.
Кері қайту: алдымен n = 2 шақыруы жалғасып, 2 шығарады; кейін n = 3 → 3, соңында n = 4 → 4.
Әр print жеке жол шығарады: 2, 3, 4. Мұнда сандар return арқылы қайтарылмайды; олар экранға шығарылады. Егер print рекурсивті шақырудан бұрын тұрса, шығару тереңдеу кезінде орындалар еді.

Факториалды рекурсиямен есептеу
Оң бүтін n санының факториалы — 1-ден n-ге дейінгі сандардың көбейтіндісі:
n! = n × (n − 1)!1! = 15! = 5 × 4 × 3 × 2 × 1 = 120
fact(5) нәтижесін табу үшін fact(4), одан кейін fact(3), fact(2), fact(1) есептеледі. Әр сыртқы шақыру өз n мәнін сақтап, ішкі нәтиже келгенше көбейтуді күтеді.
Практика #2 · 5! қалай есептеледі?
n ≥ 1 бүтін саны берілген. n! факториалын қайтаратын рекурсивті функция құрастыр. fact(5) шақыруының тереңдеуін және 120 мәнінің кері есептелуін сызба арқылы бақыла.
Жауабын көру · код және анимациялық сызба
def fact(n):
    if n == 1:
        return n
    else:
        return n * fact(n - 1)

print(fact(5))
if n == 1 — базалық жағдай. return n осы кезде 1 қайтарады.
return n * fact(n - 1) жолында алдымен fact(n − 1) толық орындалады. Содан кейін ғана оның нәтижесі осы шақырудың n мәніне көбейтіледі.
Кері есептеу: fact(1) = 1; fact(2) = 2 × 1 = 2; fact(3) = 3 × 2 = 6; fact(4) = 4 × 6 = 24; fact(5) = 5 × 24 = 120.
Тек соңғы сыртқы print экранға 120 шығарады. Ішкі return операторлары экранға ештеңе шығармайды.

0! мәнін де есептеу
Математикада 0! = 1. Жоғарыдағы n == 1 базасы бар мысал n ≥ 1 үшін жазылған. Нөлді де қабылдау үшін базалық жағдайды n == 0 етіп өзгертуге болады. Мына нұсқаға теріс емес бүтін n беріледі:
def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n - 1)

print(factorial(0))
print(factorial(5))
Бірінші жолға 1, екінші жолға 120 шығады. n = 0 кезінде бірден 1 қайтарылады; n = 5 кезінде шақырулар нөлге дейін тереңдейді.
Дайын математикалық функция
Факториалды стандартты math модуліндегі дайын функциямен де есептеуге болады:
import math

n = 5
print(math.factorial(n))
import math модульді қосады. math.factorial(n) теріс емес бүтін n санының факториалын қайтарады. Нәтиже: 120. Дайын функцияны қолданғанда рекурсивті кодты өзің жазбайсың; жоғарыдағы сызба рекурсивті тәсілдің жұмысын түсіндіреді.

04 · ЖОЛДАРМЕН ЖҰМЫС
Жолдармен жұмыс
Мақсат: жолдағы символдарды индекс арқылы алу, кесінді құру және жолдық әдістерді қолдану.
Жол (str) — символдар тізбегі. Ол бір немесе қос тырнақшаға алынады. Бір символ да, бос мәтін де жол бола алады. Python жолдары Unicode таңбаларын, соның ішінде қазақ әріптерін сақтайды.
ASCII — Unicode құрамындағы 0–127 кодтар аралығы. Мысалы, A коды — 65. Қазақ және кирилл әріптері ASCII-мен шектелмейді. ord() символдың Unicode кодын, chr() кодқа сәйкес символды береді.
print(ord('A'))
print(chr(65))
Нәтиже: бірінші жолда 65, екінші жолда A. Жол өзгермейтін типке жатады: әдістер мен кесінділер бастапқы жолдың символдарын орнында өзгертпейді.
Жол құру, біріктіру және қайталау
+ екі жолды біріктіреді, ал * бүтін санға көбейту арқылы жолды қайталайды.
s = 'Қазақстан'
d = '2050'
print(s + ' ' + d)
s = 'АЛАҚАЙ!'
s3 = s * 3
print(s3)
«2050» — жол. Оны s мәтініне қосуға болады. Бос орынды қосу үшін бөлек « » жолы жазылады.
Қайталау кезінде арасына бөлгіш автоматты түрде қосылмайды. print() тек дайын нәтижені шығарады.

1-сурет · Символдардың орналасу сызбасы
Символды бас немесе индексті өзгерт. Код сол индекстегі символды шығарады. Индекс 0-ден басталады; −1 соңғы символды білдіреді.
s = 'информатика'

Кесінді: s[start:stop:step]
start — бастапқы индекс, stop — кірмейтін соңғы шекара, step — қадам. Оң қадамда басталуы жазылмаса 0, соңы жазылмаса жолдың ұзындығы алынады. Қадам көрсетілмесе 1 болады.
Теріс қадам жолды кері бағытта аралайды: s[::-1] — кері жол, s[::-3] — соңынан бастап әр үшінші символ. Қадам 0 бола алмайды. Кесіндідегі шекара жолдан асып кетсе, ол бар бөлікпен шектеледі.
Кесінділер және max(), min()
Оқулықтағы барлық өрнекті қадамдап орындаймыз. Кесіндіде соңғы шекара кірмейді; max() және min() символдарды Unicode коды бойынша салыстырады.
s = 'информатика'
print('s=', s)
print('s[2:7]=', s[2:7])
print('s[2:7:2]=', s[2:7:2])
print('s[5:]=', s[5:])
print('s[:4]=', s[:4])
print('s[:-3]=', s[:-3])
print('s[-3:]=', s[-3:])
print('max(s)=', max(s))
print('min(s)=', min(s))
s[2:7] → форма; s[2:7:2] → фра.
s[5:] → матика; s[:4] → инфо; s[:-3] → информат; s[-3:] → ика.
max(s) → ф (Unicode 1092), min(s) → а (1072). Бұл сөздіктегі әріп ретімен сұрыптау емес. Бастапқы s өзгермейді.
